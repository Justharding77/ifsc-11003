Final Project Revision and Reflection

One thing I thought was difficult about my final project was keeping all of my code organized between the different HTML pages. I had multiple pages like home, about, recipes, reviews, and contact, and sometimes I would accidentally break a link or type a file name wrong which caused the page or images not to load correctly. I learned that even one small mistake in the code can completely mess up part of the website.

Another thing that was challenging was the CSS styling. At first, a lot of the pages looked too similar and basic, so I kept rewriting sections of the CSS to make the website look more unique and match the style of my restaurant website. I changed colors, borders, layouts, rounded corners, backgrounds, and image sections multiple times until it started looking better and more professional.

One thing I think went well was learning how to use Flexbox and CSS Grid more effectively. Before this project, I did not fully understand how to position sections evenly on a page. By working through the layouts and fixing mistakes, I got better at spacing content, organizing sections, and creating cleaner designs for the website.

I also liked being able to use real images, reviews, and business information because it made the project feel more real instead of just another school assignment. Adding food pictures, customer reviews, and the contact form made the website feel more complete and gave me more experience working with real website content.

Overall, this project taught me that coding a website takes patience because there were many times where the CSS would break, pictures would disappear, or pages would stop working correctly. Even though it was frustrating sometimes, fixing those problems helped me understand HTML and CSS a lot better and made me more confident working with web design.
